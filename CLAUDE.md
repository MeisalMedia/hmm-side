# hmm-side

Nettsiden til Hmm (huskelista, repoet `Hmm`): hjelp og personvern for App Store,
servert av GitHub Pages fra `main`. Ren HTML og CSS, ingen bygging.

- Kommunikasjon, kommentarer og commit-meldinger på norsk.
- Norsk først, engelsk under på samme side.
- Personvernsiden må stemme med «App Privacy» i App Store Connect og med det
  appen faktisk gjør. Endres appen, endres siden.
- Ny branch og PR for hver endring.
