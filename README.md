# hmm-side

Nettsiden til Hmm, huskelista. To sider, ren HTML og CSS, servert av GitHub Pages
fra `main`:

- `index.html`: hjelp og kontakt (Support URL i App Store Connect)
- `personvern.html`: personvernerklæringen på norsk og engelsk (Privacy Policy URL)

Står det noe om data her, må det stemme med «App Privacy» i App Store Connect,
som i dag sier «Data Not Collected». Samler appen en dag inn noe, endres begge.
